# 设备接入协议（一期最小实现）

平台作为 TCP 服务端，默认监听 `8768`。充电桩（或集中器）通过网线/4G 主动连接平台并保持长连接。

## 帧格式

| 字段 | 长度 | 说明 |
| --- | --- | --- |
| 起始符 | 1 | 固定 `0x68` |
| 命令字 | 1 | 见下表 |
| 设备编号长度 | 1 | deviceNo 的 ASCII 字节数 |
| 设备编号 | N | ASCII，平台创建桩时生成 |
| 数据长度 | 1 | data 字节数 |
| 数据 | M | 命令相关 |
| CRC16 | 2 | Modbus CRC16（多项式 0xA001，初值 0xFFFF），**低字节在前** |

CRC 计算范围：从起始符到数据域最后一个字节。

## 命令字

| 方向 | 命令字 | 含义 | 数据域 |
| --- | --- | --- | --- |
| 设备 → 平台 | `0x01` | 登录 | 设备密钥 ASCII |
| 平台 → 设备 | `0x81` | 登录应答 | `OK` / `AUTH_FAIL` |
| 设备 → 平台 | `0x02` | 心跳 | 空 |
| 平台 → 设备 | `0x82` | 心跳应答 | 空 |
| 设备 → 平台 | `0x03` | 实时数据 | 枪号(1) + 累计电量 Wh(uint32 大端) + SOC(1) + 状态(1) |
| 平台 → 设备 | `0x83` | 数据应答 | 空 |
| 平台 → 设备 | `0x10` | 启动充电 | 枪号(1) + 订单号 ASCII |
| 平台 → 设备 | `0x11` | 停止充电 | 枪号(1) + 订单号 ASCII |
| 平台 → 设备 | `0x12` | 参数下发 | 枪号(1) + 参数 |
| 平台 → 设备 | `0x13` | 重启 | 空 |
| 设备 → 平台 | 其他 | 交易记录/事件 | 自定义，平台统一回 `0x80 | cmd` |

## 行为约定

- 设备登录后 5 分钟内没有收到任何帧，平台主动断开；设备需定时发心跳。
- 平台下发的启停指令如果设备离线，会存入 `device_commands` 表，设备下次登录时自动补发。
- 实时数据里的累计电量用于更新订单 `energy_wh`，结算时按场站 `priceCentsPerKwh` 计算金额。
- 一期**不实现**：离线卡数据同步、并充、OTA 远程升级、分时段电价。这些协议帧可按后续需求追加，不影响现有业务流程。

## 云端协议适配

如果要接云快充平台，需要把本文件的命令字和数据域替换为平台协议（你提供的《充电桩与云快充服务平台交互协议 V1.6》），并保留业务层的预约/钱包/结算逻辑。适配工作集中在 `internal/device/protocol.go` 与 `gateway.go` 的 `handleFrame`。
